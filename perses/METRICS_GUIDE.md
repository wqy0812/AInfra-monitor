## a3-monitoring / A3 · 缓存

[打开看板](http://122.247.53.162:18431/projects/a3-monitoring/dashboards/a3-cache)

### 实例 KV 缓存占用

指标含义
vLLM 实例已分配 KV Cache 的占用比例乘以 100。按实例/角色区分；分母是该实例的 KV Cache 容量，不是整张 NPU 的显存容量。

Y 轴单位
百分比；图中 50 表示 50%，不是 0.5。

曲线与范围
A3 环境。图例区分节点、角色、实例、设备或统计分位数；筛选器仅改变所选序列，不自动生成集群去重汇总。

时间口径
容量、队列和状态表示观测时刻值；服务请求/Token 速率由源监控按连续采样间隔计算。 当前看板默认最近 1 小时、15 秒刷新；X 轴为时间。刷新间隔与统计窗口是不同概念。

零值与空白
缺样、过期或有效性检查不通过时留空。No data 不等于零；正常有效的零值才表示测得为零。 派生指标须满足 monitoring_chart_valid=1；原始数值存在但标记无效时也不显示。

### 主机 CPU

指标含义
主机 CPU 忙碌时间占总 CPU 时间的比例。当前查询扣除 idle 和 iowait，再按主机汇总；100% 表示接近全部 CPU 时间处于其余状态。iowait 被扣除，所以该图不能单独排除存储等待。

Y 轴单位
百分比；图中 50 表示 50%，不是 0.5。

曲线与范围
A3 环境。图例区分节点、角色、实例、设备或统计分位数；筛选器仅改变所选序列，不自动生成集群去重汇总。

时间口径
速率使用最近 1 分钟滚动窗口；比例使用同一窗口的分子和分母。 当前看板默认最近 1 小时、15 秒刷新；X 轴为时间。刷新间隔与统计窗口是不同概念。

零值与空白
缺样、过期或有效性检查不通过时留空。No data 不等于零；正常有效的零值才表示测得为零。 速率窗口的采样、生命周期或计数重置检查不通过时留空。

CPU 数据来源
