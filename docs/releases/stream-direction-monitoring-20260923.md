# 流停顿方向监控

页面的网关生成监控展示「后端最长未更新时间」和「写持续最长时间」，沿用环境及历史范围筛选。每个时间点取当前请求最大值，不是整个查询窗口的峰值；两项可以来自不同请求。

## 指标口径

| Prometheus gauge（秒） | 历史 API 字段 | 口径 |
| --- | --- | --- |
| `aigate_stream_backend_wait_max_seconds` | `points[].gateway.backend_wait_max_seconds` | 当前正在读取上游、观察有效且未结束的流，自上次有效输出以来累计 Read 等待，加上当前尚未返回的 Read 耗时 |
| `aigate_stream_write_active_max_seconds` | `points[].gateway.write_active_max_seconds` | 当前正在写出的流，本轮 Write 至 Flush 返回前的持续时间 |

两项均使用 `request_scope="streaming"`，按 backend 输出；页面按环境取最大值，不求和。有效空闲为零，缺失、不完整、过期、抓取失败或跨重启窗口留空，缺样断线。旧版网关没有新指标时不回填旧指标。旧指标及历史 API 字段保留原义。

后端等待从首次读取响应体开始，不包含路由、连接或等待响应头。新的有效 SSE 增量清零累计等待，复用现有正文、推理、拒绝及工具调用识别；心跳、空事件、usage 和结束标记不重置计时。所有写出耗时均排除，例如读取等待 2 秒、写出阻塞 20 秒、再读取等待 3 秒，后端等待为 5 秒。

收到完整结束信号后不再统计后端等待，但最终写出仍计时。初始响应刷新和最终错误写出也纳入写持续时间。未知/无效 SSE 退出后端等待统计，保留写出观察；退出请求后清理活跃状态。读取和写出仅更新已有活跃请求内存表，不增加逐请求定时器、逐块日志、TCP 采集或模型调用。

这两项只定位阻塞方向。后端等待包含模型服务及其到网关之间的链路；写出阻塞提示网关输出路径可能存在背压，不能单独断定调用方停止读取。短于抓取周期的阻塞可能没有被采样到。

## 验证与发布

- Go：可控时钟验证读写耗时隔离、心跳/有效增量、结束/未知/非流式排除、多请求最大值和作用域；可控 Reader/Writer 验证真实转发接线、Write/Flush 阻塞和失败、取消清理及并发抓取。
- 查询：测试新旧字段兼容、独立失败边界，以及本地一次性 VictoriaMetrics 的新鲜度、缺样、部分后端、重启和真实查询结果。
- 页面：1920×1080 Playwright 验证零值、缺样、曲线断线、旧 API、查询故障隔离和环境切换。
- Go 构建与测试使用 `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go test -mod=vendor -race ./...`。
- 发布顺序：网关指标 → 监控查询接口 → 页面/Perses。新指标没有发布前页面留空。本次仅本地实现与验证，不执行远程发布。
