# 时间范围、刷新与历史查询缓存

## Perses 时间范围

perf.3 补丁在当前标签页的 sessionStorage 中保存最近时间范围，跨看板和项目继承。显式 URL 范围优先，相对范围继续滚动，绝对范围保留毫秒；继承后替换 URL，不增加浏览历史。节点、角色和刷新周期不随时间记忆继承。存储不可用时使用 URL 和看板默认值。

仅当页面可见、范围相对且刷新周期非零时定时查询。隐藏时停止定时器，恢复可见时补查一次。固定窗口保留手动刷新并显示暂停提示，切回相对范围恢复原周期。图表和变量查询不会因窗口焦点或网络重连额外刷新。

实现、构建与版本锁见 [Perses 性能维护](../perses/performance/README.md)。`tests/ui.test.cjs` 覆盖查询和路由行为，`tests/browser-navigation.cjs` 覆盖 1920×1080 合成接口下的时间继承、URL 优先、隐藏/恢复和固定窗口；合成验证不代表真实指标或线上性能。

## monitoring-api 历史缓存

每环境最多保存 8 个历史结果，LRU 淘汰、单调时钟计时、TTL 5 秒。相同起止时间、步长、hours、view 共享在途查询；共享任务和 HTTP 调用有 8 秒期限。调用者取消不取消其他等待者，失败结果不缓存，服务退出时回收共享任务。

此缓存用于 monitoring-api，不在 Perses 直接查询 VM 的路径上。返回值保留原统计口径、空值和真实断档；缓存命中不表示采集健康。
